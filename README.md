## О проекте

Консольный архиватор без потерь. Частым байтам сопоставляются короткие коды, редким — длинные. Программа упаковывает один или несколько файлов в архив `.huf` и восстанавливает их обратно.

## Структура

| Путь | Что внутри |
| --- | --- |
| `src/` | Исходный код архиватора |
| `tests/` | Модульные и интеграционные тесты |
| `experiments/experimentsFiles/` | Файлы для замеров |
| `experiments/output/` | таблица результатов экспериментов |

## Модули

| Файл | Назначение |
| --- | --- |
| `bitIO.c` | Запись и чтение битов через байтовый буфер |
| `priorityQueue.c` | Очередь с приоритетами на минимальной куче |
| `huffman.c` | Дерево Хаффмана, кодовая таблица, проверка Крафта |
| `compress.c` | Сжатие одного файла |
| `decompress.c` | Распаковка одного файла по таблице частот |
| `archive.c` | Несколько файлов в одном архиве `.huf` |
| `main.c` | Командная строка |

У каждого файла в архиве свой путь, свои частоты и свой сжатый поток. В заголовке файла лежит таблица частот 256 байтов. Распаковщик строит по ней то же дерево, что и упаковщик.

## Сборка

Нужны CMake и компилятор C (GCC).

Linux:

```bash
cmake src -B build
cmake --build build
```

## Команды

Пути к файлам задаются относительно текущего каталога. Абсолютный путь архиватор не принимает.

Справка:

```bash
./build/huff --help
```

Сжать один или несколько файлов:

```bash
./build/huff c archive.huf input.txt
./build/huff c archive.huf file1.txt file2.txt
```

Показать содержимое архива: исходный размер, сжатый размер и путь.

```bash
./build/huff l archive.huf
```

Распаковать в текущий каталог или в указанный:

```bash
./build/huff x archive.huf
./build/huff x archive.huf restored
```

## Тестирование

```bash
ctest --test-dir build
```

| Тест | Что проверяет |
| --- | --- |
| `testBitIo` | Запись и чтение битов, дополнение последнего байта нулями |
| `testPriorityQueue` | Пустая очередь и порядок извлечения весов |
| `testHuffman` | Дерево, коды, проверка Крафта, кодирование и восстановление |
| `testCompress` | Сжатие и распаковка одного файла, в том числе пустого и большого |
| `testArchive` | Несколько файлов, команды `c`, `x`, `l` и повреждённый архив |

На GitHub Actions после сборки запускаются те же тесты, а также проверка clang-tidy.
